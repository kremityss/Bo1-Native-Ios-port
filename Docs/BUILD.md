# Build and asset workflow

## Engineering status

Native foundation only. **This is NOT Call of Duty: Black Ops, a finished port, or a runnable original BO1 game**. The scene generated by Tools/generate_demo.py is entirely original test geometry. No proprietary binaries, maps, weapons, models, or audio are bundled. Native game rendering uses Metal, ahead-of-time compiled ARM64, and **does not depend on WebKit, Wine, or JIT**.

## Source-code and feasibility references

- [OpenT5](https://github.com/paleauraaaa/OpenT5) — early Rust engine research, no complete gameplay implementation.
- [OpenAssetTools](https://github.com/Laupetin/OpenAssetTools) — T5 fastfile model/material/animation/weapon dumping, with unsupported GfxWorld and clipMap at the time of writing.
- [Open Fastfile](https://github.com/eithan1231/open-fastfile) — *experimental* importer with T5 geometry, collision, viewmodel, and related exports; rendering/gameplay are browser based, not suitable as a native port. **The native project does not include or copy their source code.** Follow each upstream project's license.

## On Windows/Linux/macOS with a BO1 install

Run the inventory tool (does not decrypt or change data):

~~~bash
python3 Tools/scan_install.py '/path/to/Call of Duty Black Ops' --out local_install_inventory.json
~~~

Do not commit inventory reports, game executables or assets to a public repository.

For *asset extraction*, separately clone upstream Open Fastfile and follow its [import documentation](https://github.com/eithan1231/open-fastfile/blob/main/docs/cod/README.md). With a working Python environment and your legitimate installation, upstream currently documents:

~~~bash
python3 -m scripts.cod doctor
python3 -m scripts.cod maps --game bo1
python3 -m scripts.cod export --game bo1
~~~

Import results vary by title, map and upstream version. This project's converter accepts individual **static** glTF 2.0/GLB files, not .ff directly:

~~~bash
python3 Tools/gltf_to_raven.py '/path/to/export/mesh.glb' Assets/scene.rvn --scale 1.0
~~~

- The default scale is 1.0. Determine source units before choosing another value.
- glTF and GLB static triangles are supported; skinned meshes and materials require additional work.
- Current converter applies hierarchical transforms and exports indexed triangles.
- BaseColorFactor becomes a flat vertex color.
- **Textures, animated props, scene scripting and per-instance map placements are not yet implemented.**

## To generate an Xcode project and native iPhone app

On a Mac with compatible Xcode and xcodegen:

~~~bash
brew install xcodegen
python3 Tools/generate_demo.py
xcodegen generate
xcodebuild -project BO1NativeFoundation.xcodeproj -scheme BO1NativeFoundation \
  -destination 'generic/platform=iOS' -configuration Release CODE_SIGNING_ALLOWED=NO build
~~~

For a signed IPA, configure an Apple developer signing identity and provisioning profile, or sign the unsigned bundle using a credential you control. An unsigned IPA is **not directly installable** until signed. The GitHub workflow attempts unsigned simulator and physical-device compilation. Its successful completion must be verified from actual Actions jobs.
